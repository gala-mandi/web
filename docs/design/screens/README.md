# Shop panel screens — design record (ticket 42)

Every non-auth screen of the shop panel **as built**, in the same style as the auth screens
(ticket 40). The design canvas is private, so these pictures are the record the owner approves
module by module; a frontend change to a screen should keep its picture true (or update it).

- Each `<screen>-desktop.png` / `-phone.png` shows **English | Urdu** side by side at 1440×900
  (scaled to half) and 390×844 (full size, long pages cut at 2,400 px).
- Each `<screen>-states-desktop.png` / `-phone.png` shows the list's **empty | loading | error**
  states (English).
- `parchi/` holds the printed parchi as the printer gets it (print media, paper width).
- Data is a realistic fake shop (Demo Mandi, Okara, Friday 6 Nov 2026); every API call is mocked
  (`e2e/screens/shop-server.ts`), so the pictures can be made again on any machine.

**Make them again:** `npm run build && npm run start`, then
`DESIGN_REVIEW=1 npx playwright test e2e/screen-gallery.spec.ts --workers=1`
(full-size shots land in `test-results/screens/`; the committed ones are palette-compressed).
The list of screens is `e2e/screens/catalog.ts`.

**Checked on every test run** (`e2e/forms-a11y.spec.ts`, `src/app/theme-contrast.test.ts`): on each
form, in English and Urdu, Tab follows the reading order, every stop shows a focus ring, focus is
never stuck (a sheet keeps focus until Escape and then gives it back), fields are 50 px on forms
(40–44 px in entry grids), and at 390 px nothing scrolls sideways or is clipped; theme contrast
4.5:1 in all six themes.
